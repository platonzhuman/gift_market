# Gift Market 38 — демо-магазин

Премиальный frontend-демо маркетплейса подарков и цветов (Иркутская область).

## Возможности

- Каталог нескольких магазинов + смена города
- Карточка, корзина, демо-checkout
- Подписка на токенах и витрина недели
- На главной — полная концепция (модель 20/20/60, экономика, roadmap)

## Запуск

```bash
cd gift-market-38
python -m http.server 8765
```
